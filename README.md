# PrismShieldAI

## Enterprise Multimodal Deepfake Detection

PrismShieldAI is a multimodal deepfake detection platform that combines:

- EfficientNet-B0
- Wav2Vec2
- Cross-Modal Attention
- Contrastive Learning
- Causal Reasoning
- Fusion Model
- Confidence Head

## Features

- Video Analysis
- Audio Analysis
- Cross-Modal Fusion
- Deepfake Classification
- Streamlit Dashboard

## Dataset

FakeAVCeleb v1.2

## Tech Stack

- Python
- PyTorch
- OpenCV
- HuggingFace Transformers
- Streamlit

## Results

- Accuracy: 99.04%
- Balanced Accuracy: 98.71%
- ROC-AUC: 99.83%
- MCC: 92.22%
